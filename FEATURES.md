# Feature Roadmap

This file tracks roadmap status. For current capabilities and usage, see the [README](README.md).

## Implemented

- Mirror Mode, including always-visible pinned fields and conditional tag/folder pins
- Inline configured tallies with `tally: Name`
- Inline checkbox habits with `checkbox: Name`
- Free-form inline counters with `counter: Name`
- Optional colors for collapsible custom-modal sections
- One-level nested custom fields through **Nest under key**

## Planned

- Timers that can be placed in custom modals or rendered inline, with elapsed time written to the note
- Arbitrary-depth nested-property configuration beyond the currently supported single parent key
